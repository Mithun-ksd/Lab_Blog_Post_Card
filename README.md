🎨 Blog Post Card

A modern, interactive blog post card component built with HTML5 and CSS3. This project was created as part of the freeCodeCamp curriculum to practice CSS animations, hover effects, and responsive card design.

✨ Features

Eye-Catching Card Design: Clean white card with rounded corners and shadow effects.
Responsive Image: Full-width featured image with a border separator.
Smooth Animations: Hover effects with scale transformation, opacity change, and enhanced shadow.
Interactive Elements: Clickable "Read More" button with hover state color change.
Centered Layout: Uses flexbox to center the card on the viewport.
Modern Styling: Professional color palette with smooth transitions.
🛠️ Technologies Used
HTML5: Semantic structure with image, heading, and link elements.
CSS3: Flexbox layout, transitions, transforms (scale & translateY), box-shadow, and pseudo-classes.

📂 Project Structure

blog-card/
│
├── main.html
├── styles.css

🚀 How to Run

Save main.html and styles.css in the same folder.
Open main.html in your browser.
Hover over the card to see the animation effects.

🧠 What I Learned

Creating responsive card components with CSS.
Using CSS transitions and transforms for smooth animations.
Implementing hover states for interactive user experience.
Flexbox centering techniques for full-viewport layouts.
Working with box-shadows for depth and visual hierarchy.
Styling buttons and links with proper pseudo-classes.
